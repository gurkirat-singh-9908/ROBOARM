## 4. Hand-eye calibration package (new)

Created `ManualPhase1/ROBO_ws/src/handeye_calibration/` — an `ament_python` package implementing an eye-to-hand calibration workflow using `cv2.calibrateHandEye`.

```
handeye_calibration/
├── handeye_calibration/
│   ├── __init__.py
│   ├── sample_collector.py      # captures (base→gripper, camera→target) pairs
│   ├── compute_calibration.py   # runs cv2.calibrateHandEye on the captured YAML
│   └── publish_calibration.py   # broadcasts the resulting static TF
├── config/
│   └── handeye_config.yaml      # default frame names + output paths
├── launch/
│   └── handeye_capture.launch.py
├── package.xml
├── setup.cfg
├── setup.py
└── resource/handeye_calibration
```

### Workflow

1. **Physical setup** — fix the ArUco target to the robot end-effector (eye-to-hand) or to the world (eye-in-hand). Default config: `eye_to_hand` (camera fixed, target on gripper).
2. **Collect samples**
   ```bash
   ros2 launch handeye_calibration handeye_capture.launch.py
   # In another terminal, move the arm to varied poses, then press ENTER
   # in the sample_collector terminal to capture each pose.
   # Collect ≥10 samples spread over rotation + translation.
   ```
3. **Compute**
   ```bash
   ros2 run handeye_calibration compute_calibration \
       --ros-args -p samples_file:=/tmp/handeye_samples.yaml
   # Writes ~/handeye_result.yaml with T_camera_to_base (or T_camera_to_gripper)
   ```
4. **Broadcast the TF**
   ```bash
   ros2 run handeye_calibration publish_calibration \
       --ros-args -p calibration_file:=/home/$USER/handeye_result.yaml
   ```

### Algorithm notes

- Uses `cv2.calibrateHandEye` with the Park method (`CALIB_HAND_EYE_PARK`) by default; method selectable via ROS parameter.
- Solves the AX=XB system where:
  - A = relative base→gripper transform between pose i and i+1
  - B = relative camera→target transform between pose i and i+1
  - X = the fixed transform we want (camera→base for eye-to-hand, or camera→gripper for eye-in-hand)
- Input: list of (4×4 T_base_gripper, 4×4 T_camera_target) pairs from TF2 and `/aruco/pose`.
