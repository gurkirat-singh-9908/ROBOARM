# Temp – Temporary / Experimental Scripts

Scratch scripts used during development. Not part of the main pipeline.

## Files

| File | Description |
|------|-------------|
| `aruco1.py` | ArUco marker detector with pose estimation (standalone, no ROS2) |
| `aruco2.py` | Alternative ArUco detection script |
| `ArUcoRos.py` | ArUco detection integrated with ROS2 (prototype – superseded by `ManualPhase1/ROBO_ws/src/ArUcoMarkerRos/`) |

## Note
The production ArUco implementation lives in `ManualPhase1/ROBO_ws/src/ArUcoMarkerRos/`.
These scripts are kept as lightweight standalone references.
